    Adapter behaviour

    • Open the root workspace folder.
    • Validate workspace.json.
    • Load each entity folder into memory.
    • Edit records in the UI.
    • Save creates or overwrites individual record JSON files.
    • Configuration files are preserved and workspace metadata is updated.
